## Hi there 👋

Специалист с глубоким бэкграундом в IT (работал системным администратором) и бизнес-менеджменте (опыт коммерческого директора), осознанно переходящий в сферу QA. Благодаря сисадминскому прошлому отлично понимаю устройство IT-инфраструктуры, сетей, клиент-серверной архитектуры и ОС, что помогает мне быстро локализовать баги и свободно общаться с разработчиками на одном языке. Опыт в бизнесе развил у меня продуктовое мышление, навыки ведения переговоров и системный подход к задачам.

Успешно освоил теорию и практику тестирования ПО: проектирую тест-кейсы и чек-листы, применяю техники тест-дизайна, тестирую API через Postman, работаю с DevTools, и базами данных. Ищу позицию Junior QA Engineer, где смогу усилить команду своими техническими знаниями и помогать выпускать качественный продукт, понимая его ценность как для пользователей, так и для бизнеса.
